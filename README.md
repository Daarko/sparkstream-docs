# SparkStream help articles

The help articles shown in the SparkStream app, published here so a correction can reach people without waiting for the next app update.

## How it works

- `docs.json` holds every help article and the heading it sits under.
- Each published set is for one version of SparkStream, named in its `forAppVersion` field. The app only uses a set published for the exact version it is running. Any other version keeps the articles it was installed with, so nobody reads about a button their version does not have.
- Articles are plain text: paragraphs, headings, lists, notes and code. Nothing here can add a link, a button or anything that runs.
- The Privacy Policy and Terms of Service are not published here. They live in [sparkstream-legal-public](https://github.com/Daarko/sparkstream-legal-public).

The history of this repository is the history of every published change to the articles.
